# Application Security Project

An application security project focused on protecting application data through backup and watermarking techniques.

## Project Overview

The project explored practical application security measures including:

* Data backup
* Watermarking
* Data protection
* Maintaining data integrity and traceability

## What I Worked With

* Application security concepts
* Data backup and recovery
* Watermarking
* Data protection

## What I Learned

* Practical application security principles
* The importance of protecting application data
* Backup strategies for data protection and recovery
* How watermarking can be used to support data identification and traceability

## Note

This project was completed as part of my diploma coursework. The original project files are no longer available, so this repository documents the project and concepts rather than reproducing the original implementation.
