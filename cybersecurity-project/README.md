# Wazuh Endpoint Security

A cybersecurity project focused on security monitoring and endpoint visibility using Wazuh.

## Project Overview

The project involved setting up a Wazuh security monitoring environment with:

* 1 Wazuh server
* 3 monitored endpoints
* Wazuh dashboard for monitoring and investigation

## What I Worked With

* Wazuh server setup
* Endpoint agent deployment and monitoring
* Security event collection
* Alert monitoring
* Wazuh dashboard
* Built-in Wazuh detection and monitoring capabilities

## Environment

```text
                ┌──────────────────┐
                │   Wazuh Server   │

                         │
             ┌───────────┼───────────┐
             │           │           │
             ▼           ▼           ▼
        Endpoint 1  Endpoint 2  Endpoint 3
```

## What I Learned

* Basics of SIEM and security monitoring
* Endpoint monitoring and visibility
* Security event collection and analysis
* Working with security alerts
* Using dashboards to investigate endpoint activity
* Deploying and managing a small security monitoring environment
